# NEXUS redesign

A ground-up premium storefront direction with:
- an Apple-inspired dark product launch hero
- a real-time Three.js controller assembled from custom geometry
- pointer-reactive rotation, floating motion, cinematic lighting and reduced-motion support
- finish selector, product specs and responsive composition
- full marketplace, categories, filters, product detail, wishlist, cart, search and demo checkout
- responsive layouts for desktop and mobile
- static `preview.html` plus visual QA captures

## Run

1. `npm install`
2. `npm run dev`

The existing API and Supabase-backed catalog/cart/order contracts remain intact. The `.env` file is intentionally excluded from this delivery; restore your own environment values locally.
